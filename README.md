# Power_Bi_CC_Dashboard
💳 Credit Card Analytics Dashboard — Power BI

📌 Project Overview

This project is an interactive Credit Card Analytics Dashboard built using Microsoft Power BI to analyze customer behavior, transaction patterns, revenue, and credit card performance.

The dashboard transforms raw credit card data into meaningful business insights using data cleaning, data modeling, DAX calculations, and interactive visualizations.
📊 Key Performance Indicators

The dashboard provides insights into important KPIs such as:

* 💰 Total Revenue
* 💳 Total Transactions
* 👥 Total Customers
* 💵 Total Interest Earned
* 📈 Transaction Amount
* 📊 Revenue Growth
* 🔄 Transaction Count
